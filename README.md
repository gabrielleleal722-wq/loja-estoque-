Sistema de Estoque de Loja (Produtos Eletrônicos)
 Objetivo
Sistema em Python para gerenciar o estoque de uma loja de produtos eletrônicos. Permite cadastrar produtos, controlar quantidades em estoque, aplicar descontos, buscar produtos e calcular o valor total do estoque — tudo por meio de um menu no terminal.

O projeto foi desenvolvido para praticar conceitos fundamentais de Python e Programação Orientada a Objetos (classes, herança, encapsulamento e abstração).
